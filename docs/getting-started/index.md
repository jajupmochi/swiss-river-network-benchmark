# Getting started

Pick the install path that matches your role. Every path ends up with a
working `srn` command or a running UI.

| Path | Best for | Entry |
| --- | --- | --- |
| `uv` (A) | contributors, reproducers | [Installation](installation.md) |
| `pip` (B) | existing Python users | [Installation](installation.md#b-pip) |
| Docker (C) | CI / servers with GPU | [Installation](installation.md#c-docker) |
| Desktop installer (D) | hydrologists, non-coders | [Desktop app](desktop.md) |
| LLM-agent (E) | bootstrap an agent | [LLM-agent install](llm-agent.md) |

Before you start, read the [prerequisites](installation.md#prerequisites)
— a CUDA-capable GPU is required for training and evaluation.
